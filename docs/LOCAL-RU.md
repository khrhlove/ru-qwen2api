# Локальный стенд Qwen

Панель: `http://127.0.0.1:8400/panel/`. Адрес API: `http://127.0.0.1:8400/v1`.
Это отдельный проект Compose `ru-qwen2api`. Gemini на 8083 не зависит от него.

Локальная панель открывается **без ключа и окна входа**. Compose включает `QWEN2API_PANEL_LOCAL_NO_AUTH=1` и публикует порт только на `127.0.0.1:8400`. Не публикуйте этот порт на `0.0.0.0` и не проксируйте панель в локальную сеть или интернет. Проверяются локальный Host и источник запросов браузера.

В `.env` нужен `QWEN2API_API_KEYS` для запросов к API — отключение входа в панель не отменяет ключ API. Храните его только на компьютере. Учётные данные добавленных аккаунтов хранятся в `data/accounts.json`; не публикуйте каталог `data/`. `data/config.json` задаёт параметры шлюза. Для первого аккаунта используйте пустой список `accounts`, отключённое `storage.enabled` и `pool.warm_chats_per_account: 0`.

`QWEN2API_OFFLINE=1` открывает локальный стенд: вход в панель и просмотр данных работают, обращения к Qwen заблокированы, фоновые проверки не запускаются. `/healthz` отвечает 200, `/readyz` — 503.

## Подключение своего аккаунта

1. Для рабочего режима установите `QWEN2API_OFFLINE=0` в `.env` и пересоздайте сервис из этого каталога: `docker compose up -d --no-build qwen2api`. С этого момента вход, обновление сессий и запросы могут обращаться к Qwen.
2. В Firefox перезагрузите обновлённое расширение через `about:debugging`. Нажмите **Добавить аккаунт Qwen** или откройте `http://127.0.0.1:8400/panel/#add-account`.
3. Форма одного аккаунта откроется без входа в панель. Введите почту и пароль своего аккаунта непосредственно в ней и оставьте проверку входа включённой. Расширение не читает эти поля и не запрашивает доступ к сайту Qwen.
4. Проверьте `/readyz`. Для сквозной проверки отправьте **один текстовый запрос** в «Модели и проверка». Проверка расходует квоту. Если аккаунт использует внешний вход или интерактивную проверку, штатный вход с паролем может быть недоступен.

Критерий перехода к единой панели: подтверждённый ответ `POST /v1/chat/completions` от настоящего Qwen. Локальный тест со смоделированным ответом проверяет только транспорт и формат.
